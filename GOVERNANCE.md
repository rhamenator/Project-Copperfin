# Project Copperfin Governance

Project Copperfin is owner-maintained. Richard M. Hamilton sets release scope,
appoints maintainers or reviewers, and makes final merge, security, licensing,
and release decisions. Contributors propose issues and changes; reviewers
evaluate them against repository policy and current evidence.

Decisions prioritize user safety, compatibility evidence, security,
machine-readable contract stability, localization readiness, Windows-first
MVP requirements, and clean cross-platform seams. Substantial changes should
be discussed in an issue and delivered in focused, independently verifiable
slices. Merge requires appropriate tests, documentation, provenance, and
review; repository access alone does not waive these requirements.

Contributors retain copyright and receive credit under
[`CONTRIBUTORS.md`](CONTRIBUTORS.md). Contributions use the inbound terms in
[`CONTRIBUTING.md`](CONTRIBUTING.md). Changes to the operative license or its
application/runtime/toolchain exception require an explicit owner decision
and qualified legal review before a public release candidate.

Public repository content is untrusted input to project automation. Only the
owner may authorize agent execution through the repository's controlled
intake policy and `agent-approved` label.
