# Project Copperfin Support

Project Copperfin is a pre-release community project and does not provide a
response-time or service-level guarantee.

- Read [`README.md`](README.md) and the linked documentation first.
- Use the structured bug, feature, documentation, failure, or general-feedback
  issue form for public support requests.
- Report security vulnerabilities privately as described in
  [`SECURITY.md`](SECURITY.md).
- Follow [`CONTRIBUTING.md`](CONTRIBUTING.md) when proposing a change.

Current `main` and the latest published artifacts are the supported diagnostic
baseline. Older commits and artifacts receive best-effort support. Include the
operating system, commit or artifact version, exact reproduction steps, and
sanitized logs. Never post credentials, signing keys, license keys, personal
information, proprietary customer data, or restricted source material.
