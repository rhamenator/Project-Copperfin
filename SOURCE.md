# Corresponding Source

Copyright © 2026 Richard M. Hamilton.

Official Project Copperfin binary artifacts are accompanied in the same
download artifact by an exact source archive named:

```text
Project-Copperfin-source-<40-character-git-revision>.zip
```

The archive has a top-level directory with that same revision and contains the
source code, build scripts, interface definitions, tests, license text,
additional permission, and third-party notices used for the build. The
revision must equal the workflow revision that produced the binary artifacts.

The same revision can be inspected or downloaded from:

```text
https://github.com/rhamenator/Project-Copperfin/commit/<40-character-git-revision>
```

Do not substitute the current `main` branch for the named revision when
satisfying a source request. If an official binary download is missing its
matching archive, report that packaging defect through the repository's
documentation-feedback issue form before redistributing the binary.

The complete operative terms are in `LICENSE`. The source archive and source
access do not include private signing keys, credentials, or other material
that is not Corresponding Source.
