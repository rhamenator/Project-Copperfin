# Project Copperfin Code Of Conduct

Project Copperfin expects respectful, constructive participation in every
project space, including issues, pull requests, reviews, discussions, and
project-related communications.

Welcome good-faith disagreement about design and evidence. Focus criticism on
the work, explain technical concerns clearly, and allow others to correct
mistakes. Harassment, threats, discriminatory abuse, sexualized conduct,
doxxing, deliberate intimidation, sustained bad-faith disruption, and public
disclosure of another person's secrets or private information are not
acceptable.

Report conduct concerns privately to the repository owner. If no ordinary
private channel is available, open a private GitHub Security Advisory and
clearly mark it as a conduct report. Do not publish sensitive report details
in an issue.

Reports will be reviewed as confidentially and impartially as practical.
Responses may include clarification, a warning, removal of content, temporary
participation limits, or permanent exclusion, proportionate to severity and
history. Anyone handling a report must disclose a conflict of interest and
step away when a fair alternative reviewer is available.
