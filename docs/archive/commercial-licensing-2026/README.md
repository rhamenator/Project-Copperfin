# Inactive Commercial-Licensing Archive

This directory preserves Project Copperfin's 2026 source-available,
commercial-license, contributor-agreement, migration, and legal-FAQ planning
documents for possible future reconsideration.

These documents are **inactive historical material**. They do not state the
license for the current source tree or release artifacts, do not override the
repository-root [`LICENSE`](../../../LICENSE), and must not be presented to
users as current terms. Project Copperfin is currently licensed under
`GPL-3.0-only`.

The product-license parser, verifier, and display implementation is retained
in source form but disabled by the default build policy. Re-enabling it later
requires an explicit policy decision, current legal review, updated public
documentation, and regression validation.

Release and package signing is separate: launcher inventories and artifacts
remain signed and verified to authenticate provenance and integrity. Signing
does not activate the archived monetization model.
