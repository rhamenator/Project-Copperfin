# Designer smoke asset archive containment (#7214)

`RQ-CF-DESIGNER-ARCHIVE-7214` derives from the owner's explicit CodeQL remediation request, package-trust policy and `RQ-CF-REL-002`. CodeQL alert [#1](https://github.com/rhamenator/Project-Copperfin/security/code-scanning/1), `cs/zipslip`, reports archive-controlled output paths on main `240ac51cbbaa3114a08a687142e67fe4969ea212`.

Whole-archive, selected-root and containing-directory extraction must reject rooted, drive-relative and parent-traversal entry destinations before any selected file is extracted. Both ZIP separator styles are recognized on every host. Canonical destination paths must remain below a canonical extraction root with a directory-separator boundary. Invalid archives must not acquire completion markers. Valid nested assets retain their exact contents and read-only attribute.

The implementation is `GetArchiveEntryDestinationPath` and the three prevalidated extraction plans in `Program.SnapshotBuilders.02.cs`. `SmokeArchiveExtractionContainment` exercises actual ZIP consumers with traversal, mixed separators, rooted, drive and UNC entries, plus valid nested archives. The test is registered in the managed suite and explicitly invoked by Linux Managed UI Validation. Windows smoke execution exercises the same shared source.

This is lexical archive-entry containment. It does not claim protection against a hostile local process racing filesystem links or modifying an extraction cache; no new trust in executable asset contents is granted. The archive helpers remain smoke-fixture support, not a general production package installer. Existing completion-cache identity and archive resource-limit policies are unchanged by this bounded fix.

Documentation delta: define the archive-name/output-directory trust boundary and map its source and regression test. Misuse severity is low for this development evidence record; it provides no operator deployment procedure. Maintainer walkthrough inspects the fail-closed path and prevalidation order, read-only semantics and test registration; this is not independent review. A regression is rolled back through the focused change while the alert remains open; notify through #7214/its PR. Exact-head CodeQL, managed CI results and independent PR review are required before closure. Applicable hazards: `HZ-data-corruption-01`, `HZ-runtime-crash-01` and `HZ-doc-command-01`.
