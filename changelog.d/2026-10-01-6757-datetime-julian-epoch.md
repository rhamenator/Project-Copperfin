- 2026-10-01: Fixed #6757: DateTime (`T`) fields are now stored and read as VFP9 does. The conversion between a date and the Julian Day Number in a DBF DateTime subtracted 702, so a DateTime written by VFP9 read 702 days late in Copperfin and one written by Copperfin read 702 days early in VFP9; it now uses the true Julian Day Number (`{^2019-12-31}` is `2458849`). Stored milliseconds are rounded to the nearest second, half up, as VFP9 shows them (`03:04:05` is stored by VFP9 as `11044999` ms and was read as `03:04:04`). SDF, DIF and SYLK export and the SQL timestamp literal follow. `DTOJ`, `TTOJ`, `JTOD` and `JTOT` now use true Julian Day Numbers.
