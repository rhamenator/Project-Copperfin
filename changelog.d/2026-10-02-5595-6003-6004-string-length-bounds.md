- 2026-10-02: Length, width and count arguments are now validated before conversion and allocation
  (#5595, #6003, #6004, part of #5611). `REPLICATE('', 9007199254740992)` used to loop about 2^53 times and
  hang the host thread; an empty source or a zero/negative count now returns immediately. `PADL`, `PADR`,
  `PADC`, `FREAD` and `FGETS` accepted any width or length (a 20 MB `PADL` completed, `FREAD(h, 1E300)` was an
  undefined conversion); they now raise error 11 past the 16,777,184-byte Character string limit, as VFP9 does.
  `SPACE` uses the same shared check (error 1903, unchanged). Also pins that `INT64_MIN / -1`, `-INT64_MIN` and
  64-bit overflow are catchable error 39 (#5598, fixed by #6769) with script-level `CTOBIN` rows.
