- 2026-09-30: Fixed #5731: PRG source loading is now bounded. The runtime refuses, before allocating the memory involved, a source file over 64 MiB, more than 256 MiB of loaded program source in a session (or in one program plus its includes), a logical line (a continued statement counts as one) over 1 MiB, more than 5,000,000 logical lines in a source, and more than 4,096 `#INCLUDE` files in a program, each with a localized diagnostic naming the source, its size or line and the limit. A sparse or hostile file of any apparent size is refused from its size alone. The limits are configurable through `RuntimeSessionOptions` and `CONFIG.FPW` (`MAXSOURCEBYTES`, `MAXAGGREGATESOURCEBYTES`, `MAXLOGICALLINEBYTES`, `MAXSOURCELINES`, `MAXINCLUDEFILES`), and the runtime host reads packaged and startup source files through the bounded snapshot read and exits with `RuntimeHost.Error.SourceTooLarge`. Removing the redundant whole-source copies kept after parsing is not part of this change.
