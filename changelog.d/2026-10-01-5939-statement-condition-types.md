- 2026-10-01: Fixed #5939: the condition of a statement or clause must be Logical (or NULL, which is false), as in VFP9, instead of being truth-tested. `IF 1` raises error 9, `DO CASE ... CASE 1` error 10, a non-Logical `FOR` or `WHILE` clause (`DO WHILE`, `LOCATE`, `COUNT`, `SCAN`, `REPLACE`, `DELETE`, `GATHER` ...) error 1127, `SET FILTER TO 1` error 37 and a direct SQL `SELECT ... WHERE 1` error 1833, all catchable with `TRY/CATCH`. `ELSEIF` keeps accepting any value, as VFP9 does. Programs that used a numeric or character expression as a condition (`REPLACE ... FOR 1`, `DELETE FOR 1`) now get the error instead of touching every record. A `CALCULATE COUNT() ... WHILE <cond> IN <alias>` no longer treats its IN target as a FOR condition.
