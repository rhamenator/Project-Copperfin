- 2026-10-01: Fixed #6506: `VARTYPE(x, .T.)` returns the declared type of a NULL table field instead of `X` (Integer, Double and Float report `N`, a Memo `C`; a non-Logical second argument is error 11), `TYPE()` looks through a NULL field to its type, and a variable copied from a NULL field keeps it. SQL `COUNT(field)` counts the rows where the field is not NULL, as in VFP9 (it raised error 1127 after the statement-condition change), and `CALCULATE CNT()` is the record count (it returned 0). `SUM`, `AVG`, `MIN` and `MAX` already skipped NULLs. The NULL result of an operation, and a variable assigned the `.NULL.` literal, are still untyped.
