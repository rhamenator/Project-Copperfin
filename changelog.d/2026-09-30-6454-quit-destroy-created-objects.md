- 2026-09-30: Fixed #6454: `QUIT` now releases runtime objects to a fixed point. An object created inside another object's `Destroy` during shutdown used to be discarded without its own `Destroy` or a release record; it now gets both, exactly once, including whole chains (`Maker` -> `Late` -> `Late2`), as installed VFP9 does (verified on `09.00.0000.7423`). A per-shutdown attempted-set stops a root whose release fails from being retried forever, and an adversarial chain where every `Destroy` creates another object stops at a fixed bound of 1024 releases and reports it once through the new `runtime.shutdown.object_release_limit` event before the remainder is discarded as before. `QueryUnload`, veto handling and `ON SHUTDOWN` are unchanged.
