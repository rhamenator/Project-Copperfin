- 2026-10-01: Fixed #6142: the date and time functions take a Date or a DateTime and no longer parse a Character argument, as in VFP9. `YEAR('01/02/2024')`, `DOW('01/02/2024')`, `HOUR('12:34:56')`, `GOMONTH('01/02/2024', 1)` and the same call with a Numeric, Logical or Object argument raise error 11 (catchable with `TRY/CATCH`); `DTOT` takes only a Date and `TTOD` only a DateTime, and `GOMONTH` and `DOW` need a Numeric second argument. Convert text explicitly with `CTOD()`, `CTOT()` or `STOD()`. NULL still returns NULL. `MDY` and `DMY` are unchanged for now (#5924).
