- 2026-09-30: Decided #6572: `APPEND FROM TYPE CSV`/`DELIMITED` into a numeric field keeps rejecting (and rolling back) a value that is still wider than the field after rounding, instead of copying installed VFP9's silent conversion to `0` or silent decimal-dropping, because both discard or alter imported data with no signal. This is an intentional, documented divergence from VFP9; the whole import is rolled back (no rows are appended). Added a regression test using the issue's exact `N N(3,0)` fixture.
