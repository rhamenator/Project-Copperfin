- 2026-10-01: Fixed #5936: built-in functions now return NULL when an argument is NULL, as installed VFP9 does, instead of fabricating a value. `ABS(.NULL.)`, `LEN(.NULL.)`, `UPPER(.NULL.)`, `LEFT(.NULL., 1)`, `YEAR(.NULL.)` and about a hundred other numeric, string, date, bit and conversion functions return NULL (VARTYPE `X`), including when the NULL is in a later argument (`LEFT('abc', .NULL.)`, `PADL('a', .NULL.)`, `MAX(.NULL., 1)`). `ISALPHA`, `ISDIGIT`, `ISLOWER` and `ISUPPER` return `.F.` for NULL, and the NULL-aware functions (`ISNULL`, `NVL`, `EVL`, `EMPTY`, `ISBLANK`, `VARTYPE`, `IIF`, `INLIST`, `BETWEEN`) keep their own rules. A value read from a NULL field propagates the same way. A program that relied on `LEN(nullfield)` being `0` or `UPPER(nullfield)` being blank now sees NULL, as in VFP9; guard with `NVL()` or `ISNULL()`.
