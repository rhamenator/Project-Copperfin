- 2026-09-30: Fixed #5916: `JUSTSTEM()`, `JUSTEXT()`, `FORCEEXT()` and `DEFAULTEXT()` now follow installed VFP9 for file names that begin or end with a dot. A file name splits at its last dot with no leading-dot exception (`JUSTSTEM('.profile')` is empty, `JUSTEXT('.profile')` is `profile`), `FORCEEXT` returns an empty string for an empty stem and keeps a bare dot for `'.'`, and `DEFAULTEXT` leaves any name that already contains a dot (even a trailing one) unchanged. The expected results come from a retained 21-name by 6-extension VFP9 matrix. Database-designator matching keeps its own stem helper and is unchanged.
