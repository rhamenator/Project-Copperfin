- 2026-09-30: Fixed #5729 and #5730: a PRG whose active `#INCLUDE` target is missing or unreadable, or whose `#IF`/`#IFDEF`/`#IFNDEF`/`#ELSE`/`#ENDIF` structure is unbalanced, now stops with a file-and-line diagnostic (and the runtime host reports `status: error` with a non-zero exit) instead of silently dropping the directive or the rest of the program and reporting completion. Installed VFP9 logs compile errors for a missing include and for a stray `#ENDIF`/`#ELSE`; Copperfin also rejects an unterminated conditional, a duplicate `#ELSE` and a header that closes its caller's `#IF`, which VFP9 accepts silently, because each removes part of the program with no signal. An `#INCLUDE` inside an inactive branch is still never resolved. A program that includes a header Copperfin does not ship (for example `FOXPRO.H`) now stops with an error naming the file and line; place the header next to the program.
