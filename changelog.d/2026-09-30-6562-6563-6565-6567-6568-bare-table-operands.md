- 2026-09-30: Fixed #6562, #6563, #6565, #6567 and #6568: `APPEND FROM`, `COPY TO`, `COPY STRUCTURE TO`, `SAVE TO` and `RESTORE FROM` now follow installed VFP9 for an unquoted filename operand. A plain token such as `APPEND FROM duplicate.csv TYPE CSV`, `COPY TO bare.csv TYPE CSV`, `COPY STRUCTURE TO bare`, `SAVE TO bare.mem` or `RESTORE FROM bare.mem` is the literal file name in the default directory (default `.dbf`/`.mem`/`TYPE` extension applies) instead of being evaluated as a variable or expression, which either faulted or silently did nothing. Quoted strings, parenthesized name expressions and function calls are still evaluated.
