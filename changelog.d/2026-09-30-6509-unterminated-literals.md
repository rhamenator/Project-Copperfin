- 2026-09-30: Partly fixed #6509: the runtime expression parser now rejects an unterminated string (`'` or `"`), bracket (`[`) or brace (`{`) literal with a localized, catchable syntax error before the statement executes, instead of returning the accumulated text and treating it as a complete literal; a following statement no longer runs when the error is uncaught. Installed VFP9 rejects all four forms. Doubled delimiters and quoted braces inside a brace literal keep working. The error text is localized in all four catalogs. The static-analysis / package source-validation lane still does not flag an unterminated literal, so #6509 stays open for that.
